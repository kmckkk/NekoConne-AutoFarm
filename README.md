# Nekopara Sekai Connect _Legit Auto Farm_ 🐈

- **AFK Farming:** Clicks buttons automatically so you can go **AFK** 💤
- **Quick Story Skipping:** Automatically skips through available story chapters 👀
- **Simple to use:** Just open the app, press **F6** to _Start/Stop_, and **F7** to Exit ✅
- **External & Safe:** Simulates normal mouse clicks without modifying game files, meaning **no risk** 👌
