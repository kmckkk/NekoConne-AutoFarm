# Nekopara Sekai Connect _Legit Auto Farm_ 🐈

- **AFK Farming:** Clicks buttons automatically so you can go **AFK**
- **Simple to use:** Just open the app, press **F6** to Start/Stop, and **F7** to Exit
- **External & Safe:** Simulates normal mouse clicks without modifying game files which, meaning **no risk**
